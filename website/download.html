A retro-styled desktop IPTV player and media centre — your streams, your channels, your TV.

  • Channel Builder: Build custom channels from video files on your computer. Click ＋ Add Channel → ► OPEN CHANNEL BUILDER to pick files or entire folders, drag to reorder, toggle shuffle and commercial breaks — then save as an M3U playlist in the playlists/ folder. No manual file editing required. v2.0
  • M3U Playlist Import: Import channels directly from local or remote M3U/M3U8 playlists. Available in the Channel Editor (⬇ Import M3U), Settings dialog (⬇ Import M3U…), and the first-run setup wizard. Channel names, stream URLs, and tvg-id EPG IDs are parsed automatically. v2.0
  • Fullscreen Overlay: Mouse-triggered floating control bar in fullscreen mode. Move your cursor to reveal channel navigation (◀◀ / ▶▶), transport controls (⏮ / ⏸ / ⏭ for local files), seek slider, volume slider, EPG toggle, and exit button. Auto-hides after 3 seconds of inactivity. Works even when VLC's hardware surface absorbs normal mouse events. v2.0

  • Guide Livestream Preview: Channel 00 now features a split-screen layout: the bottom two-thirds shows the full EPG grid, while the top third displays a live video preview playing a random channel from your lineup. The preview shows the channel name and is click-to-tune. v2.0

If the stream freezes, RetroTV automatically reconnects with a 10-second safety deadline to prevent infinite retry loops. A stuck-state fix ensures that reconnect attempts that silently fail are retried instead of leaving the channel broken forever. v2.0

⚙️ System Requirements

Windows Users (Standalone Executable):

  1. Windows 10 or 11
  2. VLC Media Player (64-bit)
    • Required for decoding video streams.
    • The installer detects whether 64-bit VLC is already installed. If it isn't (or only the 32-bit version is), the installer tells you and links to the download page.
    • Download VLC
  3. ffmpeg (included in installer)
    • Bundled with the Windows installer — no separate download needed.
    • Required for DVR recording and scheduled recordings.

Linux Users (.deb package):

  1. 64-bit (x86_64) Debian / Ubuntu or a derivative — built on Ubuntu 22.04, so Ubuntu 22.04+ or Debian 12+ (or any distro with an equal or newer glibc).
  2. A desktop session (X11, or Wayland via XWayland) — video is embedded using X11.
  3. VLC libraries — installed automatically as dependencies of the package: libvlc5, vlc-plugin-base and vlc-plugin-video-output (plus python3-tk). You do not need the full VLC application.
  4. ffmpeg (optional, for DVR recording)
    • Not bundled on Linux. Install with sudo apt install ffmpeg.

Mac / Linux Users (Python Source):

  1. Python 3.8+
  2. VLC Media Player installed on your system.
  3. python-vlc module: 
    pip install python-vlc
  4. ffmpeg (for DVR recording)
    • Install via your package manager (e.g. brew install ffmpeg or apt install ffmpeg).
  5. Pillow (Optional): Recommended for transparent PNG watermarks and EPG channel icons. 
    pip install Pillow
  6. screeninfo (Optional): For proper multi-monitor fullscreen detection. 
    pip install screeninfo

🚀 Installation & Usage

Option A: Windows Executable

  1. Download retrotv_setup.exe from the GitHub release page.
  2. Ensure 64-bit VLC is installed. The installer checks for it and will prompt you if it's missing.
  3. Run the installer — ffmpeg is included automatically, no extra steps needed.
  4. First-launch setup: On first run, the Setup Wizard will guide you through choosing a channel source — curated channels from N5 Networks, or import your own M3U/M3U8 playlist. v2.0
  5. Add more streams anytime via the Channel Editor (✎ EDIT), Settings dialog (⚙ → Import M3U), or by editing user_config.json.

Option B: Linux (.deb)

  1. Download retrotv_2.2.2_amd64.deb from the GitHub release page.
  2. Install it from the folder you downloaded it to (this also installs the VLC libraries it needs): 
    sudo apt install ./retrotv_2.2.2_amd64.deb
    Use apt install rather than dpkg -i so dependencies are resolved automatically.
  3. Launch RetroTV from your application menu, or run retrotv in a terminal.
  4. Where your data lives: settings, channel config, DVR schedule and the log file are stored per-user in ~/.local/share/retrotv/ (or $XDG_DATA_HOME/retrotv/).
  5. Uninstall: sudo apt remove retrotv (your data in ~/.local/share/retrotv/ is kept).
  6. A standalone binary, retrotv-linux-x86_64, is also on the release page for non-Debian distros. It still needs the VLC libraries installed from your package manager.

Option C: Python Source (Mac/Linux/Windows)

  1. Ensure Python 3.8+ and VLC are installed.
  2. Install the VLC binding: pip install python-vlc.
  3. For DVR recording, install ffmpeg via your package manager.
  4. Run the app: python retro_tv.py.
  5. On first run, the Setup Wizard will help you configure channels.

🔴 DVR Recording

RetroTV includes a built-in DVR system for recording live streams. Recordings are saved as transport stream (.ts) files that can be played back in RetroTV or any video player.

Quick Record

  • Press R or click ● REC to start recording the current channel immediately.
  • Press R again or click ■ STOP REC to stop. The recording is saved to the recordings/ folder.
  • A blinking ● REC indicator appears on screen while recording is active.

Scheduled Recording

  • Open the EPG guide (tune to CH 00) and click any programme cell to see a detail popup with title, time, category, and description. Click ● SCHEDULE RECORDING to set it up. v2.0
  • Scheduled recordings appear with a red dot indicator in the EPG grid.
  • Or use 📅 DVR SCHED → ➕ Manual to set a manual time-based recording — pick a channel, date, start time, and stop time. v2.0
  • Pending schedules are re-armed automatically when the app starts.

Recordings Library

  • Click 📼 LIBRARY to open the recordings manager.
  • Browse recordings by date and file size. Play recordings in-app or delete them.
  • Click 📂 Open Folder to access the recordings directory directly.
  • While playing a DVR recording, click ■ EXIT DVR to return to your live channel.
  • Active recordings show real-time elapsed time and a REC/STOP toggle right in the library dialog. v2.0

Note: DVR recording requires ffmpeg. The Windows installer includes ffmpeg automatically — no extra download needed. Mac/Linux users running from source should install ffmpeg via their package manager (e.g. brew install ffmpeg or sudo apt install ffmpeg).

⏾ Sleep Timer

RetroTV includes a sleep timer that automatically shuts down the app after a specified duration. This is perfect for falling asleep to your favorite channels.

  • Click ⏾ SLEEP in the control bar to open the timer dialog.
  • Choose a preset duration: 15, 30, 45, 60, 90, or 120 minutes. Or enter a custom number of minutes.
  • The button shows a live countdown (e.g. ⏾ 45:23) while the timer is active.
  • Click the countdown button again to cancel the timer.
  • DVR-safe: If a DVR recording (manual or scheduled) is active when the timer fires, RetroTV mutes the audio and minimizes to the taskbar instead of closing — so your recording finishes cleanly.

🛠️ Custom Channels & Playlists

You can create your own channels using the built-in Channel Editor (click the ✎ EDIT button in the control bar). The editor now offers two paths when adding a channel:

  • Use Existing Playlist / Live URL: Paste a stream URL or reference an M3U/XSPF playlist file. v2.0
  • Open Channel Builder: Pick video files or folders from your computer, reorder them, toggle shuffle and commercial breaks, and save as an M3U playlist. v2.0

The editor also supports importing channels from Extended M3U playlists via the ⬇ Import M3U button.

Alternatively, you can create a user_config.json file manually next to the executable or script. The file supports two formats:

Format 1 — Simple list (legacy):

[
  {
    "name": "My Movies",
    "playlist": "my_movies.xspf",
    "random": "1",
    "watermark": "my_logo.png",
    "channel-id": "MyMovies.us"
  },
  {
    "name": "My Live Stream",
    "url": "http://192.168.1.100:8080/stream.m3u8"
  }
]

Format 2 — Dict with EPG sources (recommended):

{
  "channels": [
    {
      "name": "My Movies",
      "playlist": "my_movies.xspf",
      "random": "1",
      "commercials": "1",
      "watermark": "my_logo.png",
      "channel-id": "MyMovies.us",
      "description": "Classic Films"
    },
    {
      "name": "My Live Stream",
      "url": "http://192.168.1.100:8080/stream.m3u8",
      "description": "Webcam"
    }
  ],
  "epg_urls": [
    "https://example.com/my-guide.xml",
    "/path/to/local-guide.xml"
  ]
}

The app will automatically load these channels alongside the default lineup. Supported fields:

FieldRequiredDescription
nameYesDisplay name for the channel
urlOne of url/playlistLive stream URL (HLS/m3u8, DASH, etc.)
playlistOne of url/playlistPath to XSPF, M3U, or M3U8 playlist file
randomNoSet to "1" to shuffle playlist order
commercialsNoSet to "0" to disable commercial breaks on this channel (default: enabled)
watermarkNoPath to a transparent PNG shown bottom-right
channel-idNoMatches this channel to an entry in the XMLTV guide data
descriptionNoShort description shown in the channel guide
colorNoHex accent color e.g. "#ff6600"

The epg_urls array in the dict format lets you specify additional XMLTV sources that are merged with the built-in guide on startup. You can also manage EPG sources through the 📡 EPG button in the control bar.

📺 Commercial Breaks

To enable automatic commercial breaks between your local video files:

  1. Create a playlist file named commercials.xspf, commercials.m3u, or commercials.m3u8 in the same directory as the app.
  2. Or, place video files directly into a folder named commercials/.
  3. The app will automatically play 2–4 random commercials between every track in your local playlists (configurable in Settings).
  4. To disable commercials on a specific channel, set "commercials": "0" in its config entry.

v2.1.0

Earlier release — a maintenance & stability update

  • Crash fix — the VLC media-teardown sequence (stop() → release old media → load new) now runs for every previous player state, not just Error. Hardware decoders (D3D11VA / DXVA2) keep GPU resources alive even while playing and could race the next channel change into a hard crash on Windows
  • Tk callback errors (key bindings, buttons, timers) are now written to retrotv.log — in the windowed build these previously went to a discarded stderr and vanished without a trace
  • Quitting during a channel load or the volume re-apply retry loop no longer hangs — the worker now checks for shutdown and bails out
  • Shutdown reworked — the window hides immediately, then VLC stop/release, the worker-thread join and DVR cleanup run off the main thread so they can't deadlock against VLC's Win32 message pump; close is guarded against double-invocation
  • Fullscreen toggle debounce rewritten — a single physical double-click can arrive twice (the Tk binding and the VLC window hook); the old guard let the second event immediately undo the first, so fullscreen flickered straight back off
  • Entering fullscreen is now idempotent — a second trigger while already fullscreen used to overwrite the saved window geometry, leaving nothing to restore on exit
  • Fullscreen now opens on the correct monitor — detection uses the window handle instead of a restore-position lookup that was wrong while the window was maximised
  • Double-click-to-fullscreen over the video is more reliable — the Win32 hook now covers every VLC child window and synthesises the double-click from two rapid clicks (VLC's own windows often don't report double-clicks), and is removed during channel changes so it can't fire on a window being torn down
  • DVR recordings now stop by sending q to ffmpeg for a clean shutdown that finalises the file — previously a hard kill could leave a truncated or unplayable recording
  • Recording a custom local-file channel now records the right file; EPG click-to-record and scheduled recordings work for local-file channels too
  • Manual DVR scheduling rejects start times in the past and converts local time to UTC correctly across daylight-saving changes
  • The ● REC button resets itself if ffmpeg exits on its own; cancelling an in-progress scheduled recording no longer corrupts its saved status
  • DVR Schedule Manager gains a 🗑 Delete button; the Recordings Library gains ▶▶ Play All for back-to-back playback
  • Channel 00 guide — the live preview is click-to-tune again, "Now / Up Next" for local channels is consistent whether or not you're tuned in, the preview no longer plays its own commercials, and the clock follows the 24-hour setting
  • EPG sources — added epg.txt (one XMLTV URL per line, placed next to the app), merged with the built-in guide and your custom sources
  • State files (retrotv_resume.json, retrotv_news.json, retrotv_settings.json) are now read and written next to the executable, so your last channel, settings and seen-news survive launching from a shortcut
  • Fresh installs no longer show the news pop-up on first launch
  • The remote curated-lineup check only runs when "Use curated channels" is enabled; for everyone else ↺ LINEUP now reloads your own user_config.json
  • Every dialog now centres on the monitor RetroTV is running on instead of sometimes opening partly off-screen
  • Hover tooltips added to the control-bar and sidebar buttons; the channel-search ✕ button no longer overlaps the search field; the fullscreen overlay's play/pause and mute buttons stay in sync with playback

⚠️ Troubleshooting

"NO SIGNAL" or Black Screen:

  • Ensure VLC Media Player is installed correctly (64-bit version for 64-bit Windows).
  • For local files, ensure the video format is supported by your VLC installation.
  • Check retrotv.log for error details — press Ctrl+L to open it.

"CHANNEL OFFLINE" or red "NOT BROADCASTING" indicator:

  • The stream is not currently available. The app will attempt to reconnect automatically.
  • Try tuning away and back. If the problem persists, the stream may be temporarily down.
  • Check retrotv.log for details — it will show the reconnect attempts.

EPG/Guide shows "No schedule available":

  • The app downloads guide data from a remote server on startup. Ensure you have an internet connection.
  • If using custom channels, ensure the channel-id in your config matches a valid ID in the EPG data.
  • You can add custom EPG sources via the 📡 EPG button or epg_urls in user_config.json.

DVR recording fails or ● REC button shows "ffmpeg Not Found":

  • Windows: The installer includes ffmpeg. If you moved the app folder after installing, make sure ffmpeg.exe is still next to retrotv_setup.exe or retrotv.exe.
  • Mac/Linux (from source): Install ffmpeg via your package manager (e.g. brew install ffmpeg or sudo apt install ffmpeg).
  • You can also download ffmpeg manually from ffmpeg.org and place it next to the app executable.
  • Check retrotv.log for ffmpeg error output.

Scheduled recording didn't fire:

  • Ensure the app was running at the scheduled start time. Scheduled recordings only work while RetroTV is open.
  • Check the DVR Schedule Manager (📅 DVR SCHED) — the entry will show "missed" if it was skipped.
  • Ensure ffmpeg is available and the stream URL is still valid.
  • When scheduling manually, the start time must be in the future — RetroTV now rejects past start times. v2.1

A recording is truncated or won't play back:

  • v2.1 stops ffmpeg gracefully (sends q) so the output file is finalised properly. Recordings from older versions that were interrupted mid-write may still be incomplete. v2.1
  • Try playing the .ts file in VLC directly — a partially written file will often still play up to the point it was cut.

Watermark has black background:

  • Install the Pillow library (pip install Pillow) for proper transparent PNG support. Without it, transparency is not rendered correctly.

Local file won't play / "BUFFERING (RETRY)" message:

  • The app will automatically retry up to 3 times with increasing delays for drive spin-up or temporary errors.
  • Ensure the file path in your playlist is correct and the drive is connected.
  • v2.0 pre-reads local files before VLC opens them to spin up sleeping drives. v2.0
  • Check retrotv.log for detailed error messages from VLC.

Volume changes have no effect:

  • Volume is re-applied after VLC's audio pipeline is fully ready — this fixes a known issue where volume was ignored on startup.
  • If the problem persists, check that your system audio device is working and not muted at the OS level.

Stream freezes and doesn't recover:

  • RetroTV includes an 8-second freeze watchdog that should auto-reconnect frozen streams.
  • v2.0 adds a 10-second safety deadline and stuck-state recovery to prevent silently broken reconnects. v2.0
  • If the stream repeatedly freezes, it may be a source issue. Try a different stream or check your internet connection.
  • Set the environment variable RETROTV_LIBVLC_DEBUG=1 and check retrotv.log for detailed VLC-level diagnostics.

Sleep timer closed the app during a recording:

  • If a DVR recording was active, the timer should have muted and minimized instead of closing. Check that the recording process was running at the time.
  • Scheduled recordings (pending but not yet started) are also detected — the timer will minimize in this case too.

Fullscreen overlay doesn't appear:

  • Move your mouse while in fullscreen — the overlay is triggered by cursor movement, not just mouse position. v2.0
  • The overlay auto-hides after 3 seconds of inactivity. Move the mouse again to bring it back.
  • On Windows, cursor position is polled at the OS level so it works even over VLC's hardware-accelerated surface.

First-run wizard doesn't appear:

  • The wizard only appears when neither tv_config.json nor user_config.json exists — i.e., a completely fresh install. v2.0
  • To trigger it manually, delete both config files and restart the app.

A dialog opened on the wrong screen or partly off-screen:

  • Fixed in v2.1 — dialogs now centre on the monitor RetroTV is running on. v2.1

Settings or last channel aren't remembered between runs:

  • v2.1 reads and writes retrotv_resume.json, retrotv_settings.json and retrotv_news.json next to the executable rather than the working directory, so launching from a shortcut now persists state correctly. v2.1
  • Make sure the app folder is writable (not under C:\Program Files without permissions).
